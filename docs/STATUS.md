# 项目状态

> 最后更新：2026-05-11 · 数据快照：2025-08

本文档记录 cn-aircraft-finder 的当前实现、能力边界与改进方向。`README.md` 面向使用者，本文件面向维护者与贡献者。

---

## 1. 当前功能

### 查询与展示

- 按注册号 / 航司 / 机型 / 联盟自由文本搜索（前端纯 JS，全量加载后即时匹配）
- 顶部 4 个筛选下拉：地区 / 联盟 / 服役状态 / 类别
- 卡片信息：机型 + 航司 + 联盟徽章 + 服役状态 + 出厂/服役/退役日期 + 序列号 + ICAO24
- 客舱比例条（F/C/W/Y 彩色 + 图例）
- 飞机照片（懒加载 + 摄影师署名）
- 5 个跳转：实时位置 / 真实座位图 / 多个照片库
- 移动端优先布局，明/暗模式自适应

### 数据源

- **OpenSky Network** 月度公开飞机数据库 —— 主源
- **Mictronics tar1090-db** 每周更新的 ADS-B 飞机数据库 —— 活跃判定第二源
- **Planespotters Photo API** —— 飞机照片（含署名）
- **手工维护** 航司 / 机型 / 客舱布局映射

### 服役状态判定

三层判定，置信度递增：

| 状态 | 判定依据 |
| --- | --- |
| 在役 | 在 Mictronics 实时库 |
| 久未活跃 | 在 OpenSky 但不在 Mictronics |
| 已注销 | OpenSky `regUntil` 早于快照月 |

### 自动化

- **GitHub Actions** 每月 5 日 03:30 UTC 自动拉数据 → 构建 → 提交 → 部署
- 每次 push 到 main 自动触发 GH Pages 部署

## 2. 架构

### 数据流

```
OpenSky 月度 CSV (~110 MB) ──┐
                              ├──> scripts/build_data.py ──> public/data/aircraft.json
Mictronics 周度 CSV (~33 MB) ─┤                              └─> public/data/meta.json
                              │                              └─> public/data/cabin_layouts.json
手工维护:                     │
  operators.json              │
  aircraft_types.json    ────┘
  cabin_layouts.json
```

前端 fetch → 一次加载到内存 → 全量搜索；照片按需调用第三方 API。

### 关键设计决定

| 决定 | 理由 |
| --- | --- |
| 纯静态托管 | 35k 条数据在浏览器里跑得动；GH Pages 免费；零运维 |
| 选 OpenSky 作主源 | 完全免费、全球覆盖、含 `regUntil` 等历史字段、无 API key |
| 引入 Mictronics 作活跃信号源 | 每周更新，是判定退役的中等置信信号 |
| 不存任何用户数据 | 全部前端，零合规负担 |
| 客舱用比例条而非真实座位图 | 真实座位图无开源数据集，比例条 + 跳转链接是平衡解 |
| 不抓取第三方网站 | 所有第三方仅做 deep-link 或调用公开 API |

## 3. 已知局限

| 问题 | 影响范围 | 现状 |
| --- | --- | --- |
| 上游数据按月更新，新机入库有滞后 | 全球 | GH Actions 每月自动刷新 |
| 客舱布局以 (航司, 机型) 为粒度，但同一对常有多种实际配置 | 全球 | 已在 `notes` 字段写明；用户可通过"报错"按钮反馈 |
| 部分注册号 operator 字段缺失 | 全球 | 前端通过照片 slug 兜底推断 |
| 已退役但 `regUntil` 仍在未来的飞机暂无法标退役 | 全球 | Mictronics "久未活跃"判定可覆盖大部分 |
| 客舱布局覆盖率约 74% | 全球 | 剩余 18% 落到机型通用配置，8% 完全无信息 |

### 覆盖范围限制

- 私人 / 通用航空 / 军用机 不在白名单（中国大陆/港/澳/台 B- 注册号宽松保留）
- 照片依赖 Planespotters 收录范围
- AeroLOPA 跳转覆盖其网站所收录的航司范围

### 前端

- 首次加载约 13 MB JSON，gzip 后 ~700 KB
- 搜索结果最多显示 80 条
- 暂无键盘快捷键 / 拼音搜索 / 历史记录

## 4. 改进方向（roadmap）

### 短期（小工作量，高价值）

- [ ] **PWA / 离线**：把 13 MB 数据存到 IndexedDB，service worker 拦截 fetch，下次完全离线可用
- [ ] **拼音搜索**：把航司名拼音首字母加进搜索 blob，让"gjhk"能匹配"国家航空"
- [ ] **最近查询**：localStorage 存最近 10 条
- [ ] **B 牌段说明**：注册号开头几位的含义（B-1xxx 中国大陆窄体等）
- [ ] **航司机队全览页**：点航司名跳到 `/op/CCA`，按机型分组显示
- [ ] **客舱配置继续补全**：目标把覆盖率从 74% 推到 85%+

### 中期

- [ ] **航司机队仪表板**：每家航司的机型分布、平均机龄
- [ ] **机型百科**：点 `A20N` 跳到 `/type/A20N`，列出该机型全球分布、首飞日
- [ ] **多语言**：加英文 UI
- [ ] **退役历史时间线**：基于历史快照差分

### 不打算做

- ❌ **每架飞机的实际座位图**：现实不可行（数据闭源 + 频繁变化）
- ❌ **订票 / 选座**：与本工具定位相反
- ❌ **用户登录 / 评论**：会引入数据 / 合规负担
